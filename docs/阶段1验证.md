# 阶段 1：Steam 房间验证

状态：双账号核心流程已验证，五人容量与版本不匹配专项测试待做。阶段 0 的游戏主菜单与 Harmony 加载已验证，本阶段只开发 Steam 房间，不涉及进度或战斗。

## 已实现的测试入口

- 主菜单按 F9 打开调试面板，显示 Steam 是否就绪、房间 ID、成员列表和状态。
- 创建最多五人的公开或仅好友房间；设置协议版本、游戏程序集 SHA-256 和原房主 Steam ID。
- 通过房间 ID、公开房间搜索或 Steam 邀请加入。加入后校验协议和游戏版本，不合时退出并显示提示。
- 主动离开；原房主离开或掉线后，客人退出当前会话。

## 目前的运行结果

2026-09-25，已在本机 Steam 版进入主菜单，F9 面板出现，用户确认公开房间创建与主动离开均成功。修订版 `Player.log` 记录了 `Stage 1 lobby overlay ready.`、`Created room ... max 5.` 和 `Left room ...`，无本 Mod 的异常。打包 DLL 与游戏安装 DLL 的 SHA-256 相同。随后用户用两个 Steam 账号验证了公开列表、房间 ID 和 Steam 邀请加入，以及房主离开后客人退出房间；两端均未发现问题。用户尚未提供客端日志或存档哈希，因此这些项目以人工验收为依据。
## 待验证

- 本机 Steam 账号：主菜单无加载错误，F9 面板出现，Steam 状态为 ready，创建房间并显示 1/5。
- 第二个 Steam 账号：搜索、邀请、房间 ID 加入、双端成员列表、主动离开及房主退出。
- 最多五人：房主加四名客人同时在房；第六人加入被 Steam 拒绝且面板给出原因。
- 两端使用不同 Mod 协议或游戏程序集哈希时，加入后给出版本不匹配提示。
- 收集双端 Player.log，确认无异常；测试前后两端游戏存档哈希不变。

只有全部验收完成，才合并到 main 并打下一版本标签。
