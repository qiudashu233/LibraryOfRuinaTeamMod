《废墟图书馆》Ruina Coop 双人测试说明

请房主和测试玩家都使用同一个压缩包：RuinaCoop-stage2-v6-snapshot-fix-test.zip。旧的 v5 包无法与本包互连。
这次只测试“加入房间、看到房主进度、同步下一关选择、离开房间”。不用真的开始接待，也不用修改卡组。

一、两个人都先安装

1. 先关闭游戏。
2. 在 Steam 中右键《废墟图书馆》→“管理”→“浏览本地文件”，打开游戏文件夹。
3. 打开压缩包，把里面的 RuinaCoop 文件夹复制到：
   游戏文件夹\LibraryOfRuina_Data\Mods\
   如果里面已经有 RuinaCoop 文件夹，请先备份旧文件夹，再用压缩包中的整个文件夹替换。
4. 检查最终路径是：
   游戏文件夹\LibraryOfRuina_Data\Mods\RuinaCoop\StageModInfo.xml
   不要变成 Mods\RuinaCoop\RuinaCoop\StageModInfo.xml。
5. 从 Steam 启动游戏，选择“LOR With Mods”。在 Mod 列表里只勾选“Ruina Coop (Development)”，然后进入游戏。

二、房主操作

1. 点“继续游戏”，进入自己的图书馆存档。
2. 按 F9 打开联机面板，点“Create public room (max 5)”。
3. 把面板上的“Room ID”数字发给测试玩家。
4. 确认右侧“Host progress”已经显示自己的章节、楼层和馆员。如果仍显示“Progress waiting”，请确认已经进入图书馆存档。
   如果显示“Host snapshot failed local validation”，请截图并保存房主 Player.log。
5. 可以先点左侧“Test Steam room messages”。显示“PASS: Steam room message and sender ID.”后，再让测试玩家加入。

三、测试玩家操作

1. 在标题画面或自己的图书馆里按 F9。你的关卡进度不需要与房主相同。
2. 把房主发来的 Room ID 填到左侧输入框，点“Join ID”。也可以接受房主的 Steam 邀请。
3. 加入成功后，两个人的面板应显示“Members: 2/5”，并列出两位玩家。
4. 看右侧“Host progress”：应该能看到房主的章节、楼层、馆员和关卡列表。请和房主对一下章节与楼层是否一致。

四、两个人一起检查

1. 房主在右侧任意一个关卡旁点“Select”。这只是标记下一关，不会开始接待。
2. 测试玩家检查“Selected next stage”是否变成和房主相同的关卡 ID；测试玩家不应有“Select”按钮。
3. 测试玩家点“Leave room”，再用同一个 Room ID 加入一次。重新加入后，应再次看到房主进度。
4. 保持测试玩家在房间里，房主点“Leave room”。测试玩家应自动退出房间。

如果出现错误，请先截两个人的 F9 面板；在再次启动游戏前，分别复制两台电脑的 Player.log 发给房主。日志位置可以直接粘贴到 Windows 文件资源管理器地址栏：
%USERPROFILE%\AppData\LocalLow\Project Moon\LibraryOfRuina\Player.log

不需要发送 Steam 密码或游戏存档。
